# Prompt 02 — 小红书信息图卡（工作流价值图）

目标平台：小红书内页卡片
画幅：3:4 竖版
风格：sketch-notes / hand-drawn-edu / clean infographic

请生成一张中文信息图卡片，解释“聊天型 AI”和“工作流型 AI”的区别，适合职场效率工具种草内容。

内容结构：
- 标题：用户不是缺 AI
- 副标题：而是缺能进入工作流的 AI
- 左侧或上方区域：聊天型 AI
  - 会聊天
  - 能回答问题
  - 但常常还要自己整理、复制、改写、切换
- 右侧或下方区域：工作流型 AI
  - 帮你起草
  - 帮你提炼
  - 帮你整理
  - 帮你输出
- 底部结论：重点不是功能多，而是能不能接住办公动作

画面要求：
- 用流程箭头、便签、文档卡片、摘要框、清单图标做视觉隐喻
- 色彩柔和但专业：奶油底、青蓝/薄荷/浅紫模块，少量珊瑚红强调
- 可爱度低，专业度更高，适合轻种草办公内容
- 强调“信息 → 整理 → 输出”的视觉路径
- 不使用真实品牌 logo，不伪造真实产品 UI
