# Prompt 03 — 小红书场景卡（办公碎活清单）

目标平台：小红书内页卡片
画幅：3:4 竖版
风格：notion / checklist / editorial productivity

请生成一张中文小红书卡片，主题是“上班最耗人的，不是大项目，而是碎但必须做的活”。

内容点：
- 写汇报
- 做总结
- 整理会议重点
- 统一沟通口径
- 把散信息变成交付内容

视觉要求：
- 像高颜值办公清单卡，而不是宣传海报
- 使用待办框、文件夹、邮件、日历、对话框、文档标签等元素
- 版面清晰，信息层级强，适合一眼扫读
- 配色：白底 / 浅灰 / 蓝绿点缀 / 少量荧光黄强调
- 气质：真实办公、轻分享、可信赖
- 避免科幻感和营销感
