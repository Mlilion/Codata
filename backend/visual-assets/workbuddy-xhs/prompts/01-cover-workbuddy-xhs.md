# Prompt 01 — 小红书封面图（Workbuddy × 腾讯AI工具）

目标平台：小红书封面
画幅：3:4 竖版
风格：notion / minimal / clean productivity / xiaohongshu-friendly

请生成一张适合小红书图文首图的中文封面，主题是“办公提效型 AI 搭子”，强调真实办公流而不是科幻炫技。

画面要求：
- 干净留白、轻科技、现代办公桌面感
- 视觉主体为：笔记本电脑、文档卡片、会议纪要卡、待办清单、对话气泡、流程箭头
- 体现“碎信息被整理成输出”的感觉：从杂乱便签/聊天记录/文档片段，流向整洁的总结卡片、汇报卡片、邮件卡片
- 不要出现夸张赛博朋克、宇宙光效、机器人脸、大脑发光等俗套 AI 元素
- 颜色以青蓝、深灰、白、浅灰为主，少量亮黄作强调
- 整体氛围：可信、清晰、高效、适合职场人收藏
- 版式预留顶部和中部较大文字区，适合叠加封面标题

建议叠字文案（供模型理解，不强求精确渲染）：
主标题：不是又一个聊天AI
副标题：更像办公流里的全能搭子
角标小字：会议 / 汇报 / 总结 / 沟通

限制：
- 不要出现真实品牌 logo
- 不要伪造具体产品界面
- 中文文字即便不精准，也应留足清晰排版空间
- 输出为高质感位图封面
