# SVG 图表规范

报告里的图表一律用**内联 SVG**（无 canvas、无 JS、无外链），保证单文件离线可看。配色、画布、坐标映射、数字格式全部按本文件写死，不自由发挥——这样多张图、多份报告之间观感一致（色板继承自 chart-renderer）。

用 `templates/` 下的 SVG 骨架起手，按坐标公式算出每个元素的 `x/y/width/height`，替换骨架里的占位符注释。

---

## 一、色板（写死 8 色）

series 按顺序取色，第 `i` 个 series 用第 `i % 8` 个颜色:

```
#4f8ff7  #f79f4f  #4fcf8f  #c77dff  #f7746f  #4fc4cf  #f7c14f  #8f9ff7
```

- 首色 `#4f8ff7`（蓝）是主色，单 series 图（单色柱状、折线、面积）默认用它。
- 文字色不取自色板，用固定值：主文字 `#111827`、次要文字/轴标签 `#6b7280`。
- 网格线：浅 `#eceff3`、基线（0 轴)`#d0d5dd`。
- 面积填充用主色的半透明:`fill="#4f8ff7" fill-opacity="0.15"`。

## 二、固定画布与边距

- bar / line / area:`viewBox="0 0 720 360"`。
- pie:`viewBox="0 0 360 360"`（正方形)。
- 边距:`padLeft = 60`、`padTop = 20`、`padRight = 20`、`padBottom = 40`。
- 绘图区尺寸:
  - `plotW = 720 - padLeft - padRight = 720 - 60 - 20 = 640`
  - `plotH = 360 - padTop - padBottom = 360 - 20 - 40 = 300`
- 绘图区边界:左 `x=60`、右 `x=700`、顶 `y=20`、底(基线) `y=320`。

## 三、坐标映射公式

设有 `n` 个数据点(`i = 0 .. n-1`)，最大值 `max`(轴上界，建议向上取整到「好看」的刻度)。

- **x(第 i 个点):**
  `x = padLeft + (i / (n - 1)) * plotW`
  即 `x = 60 + (i / (n - 1)) * 640`。
  `n == 1` 时点居中:`x = padLeft + plotW / 2 = 380`。

- **y(值 v):**
  `y = padTop + (1 - v / max) * plotH`
  即 `y = 20 + (1 - v / max) * 300`。
  v = 0 → y = 320(落在基线)；v = max → y = 20(落在顶部)。

- **柱状 bar:**
  每根柱的槽宽 `slot = plotW / n = 640 / n`；柱宽 `barW = slot * 0.7`。
  第 i 根:
  `x = padLeft + i * slot + (slot - barW) / 2`（居中于槽，等价于 `60 + (i + 0.15) * slot`）
  `barTop = padTop + (1 - v / max) * plotH`
  `barH = 320 - barTop`（= 基线 y - barTop）。

- **饼图 pie（viewBox 0 0 360 360):**
  圆心 `cx = 180`、`cy = 180`、半径 `r = 140`。
  每一块角度 `angle = value / total * 360`，从 -90°(正上方)起逐块累加。
  用 SVG `<path>` arc:某块从累计角 `a0` 到 `a1`(度)，
  `x0 = cx + r*cos(a0·π/180)`、`y0 = cy + r*sin(a0·π/180)`，`x1/y1` 同理用 `a1`；
  `largeArc = (a1 - a0) > 180 ? 1 : 0`；
  `d = "M cx cy L x0 y0 A r r 0 largeArc 1 x1 y1 Z"`。

## 四、数字格式化（继承 chart-renderer）

- **轴刻度 / 图内标注**:
  - `≥ 1e6` → 保留 1 位小数 + `M`，例 `2_340_000 → 2.3M`。
  - `≥ 1e4` → 除以 1000 取整 + `K`，例 `23_400 → 23K`。
  - 否则 → 千分位，例 `8_450 → 8,450`。
- **数据明细表 / 需要精确值处**:一律千分位，不缩写，例 `2,340,000`。
- 百分比保留 1 位小数 + `%`，例 `12.3%`。
- null / 缺失值:表格留空，图表跳过该点(不画成 0)。

## 五、类目上限

单张图类目 > **50** 时不要硬画(会挤成一团)。先聚合:取 Top N + 其余归入「其他」，或换更粗的时间/维度粒度，再画。

## 六、每种图怎么填骨架

- **柱状 `chart-bar.svg`**:分类对比。按第三节 bar 公式算每根 `x/barW/barTop/barH`，重复 `<rect>`；x 轴标签放槽中心 `text-anchor="middle"`。
- **折线 `chart-line.svg`**:趋势。按 x/y 公式算每点，拼成 `<polyline points="x0,y0 x1,y1 ...">`；可在点上叠小圆。
- **面积 `chart-area.svg`**:趋势 + 量感。同折线取点，`<polygon>` 首尾补到基线 `(x0,320)`、`(xn,320)` 闭合，半透明填充 + 顶部实线描边。
- **饼图 `chart-pie.svg`**:占比。按第三节 pie 公式逐块累加角度画 `<path>`，每块取色板第 `i%8` 色；图例列在右侧或下方。

## 七、自检清单（画完逐条确认）

- [ ] 柱高 / 点高与数值成比例？(v=0 落基线 y=320，v=max 落顶 y=20)
- [ ] 所有绘制元素都在 padding 内?(60 ≤ x ≤ 700，20 ≤ y ≤ 320)
- [ ] 饼图各块角度之和 = 360°?
- [ ] 轴刻度 3-5 档、均匀分布、用格式化后的数字?
- [ ] 每个 series 的颜色按 `i % 8` 取自色板、无自定义色?
- [ ] 文字用固定 hex(`#111827` / `#6b7280`)、无 CSS 变量?
- [ ] 无任何外链(无 http/https、无 `<image href>` 外部图)?
