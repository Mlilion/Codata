# Credibility Rules

- Bind every numeric claim to a query result or evidence identifier.
- Distinguish absolute delta, relative change, and contribution share.
- Never call a contribution a causal effect without an experiment or
  quasi-experimental design.
- State whether the metric uses an authoritative caliber or custom SQL.
- Surface truncation, missing coverage, mixed currency, incompatible periods,
  and known caliber changes.
- Treat missing rows carefully: zero and no observation are different unless the
  query or domain definition establishes that missing means zero.
