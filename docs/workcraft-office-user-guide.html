1. WorkCraft 是什么

WorkCraft 是一个运行在电脑上的 AI 办公助手。它不是单纯的问答网页，而是把聊天、文件、工具执行、产物预览、工作区记忆、自动化任务和远程访问组合在一起的本地 AI 工作台。

你可以把它理解成一位会看文件、会整理资料、会写报告、会操作文件夹的桌面小助手。你负责说清楚目标，它负责读取材料、拆解步骤、调用工具、生成结果，并在需要时向你确认权限。

它能帮你交付结果

输出不只是聊天文字，还可以是 Markdown 报告、HTML 网页、CSV 表格、DOCX/XLSX/PDF/PPTX 预览、流程图、代码或生成文件。

它能持续理解上下文

同一个任务可以在一个会话中反复追问。选择工作区后，还能为这个文件夹形成独立记忆，后续继续使用。

给办公新手的最短理解 不要把 WorkCraft 当成“搜索框”。把它当成“会操作办公文件的助理”：你要告诉它目标、材料、输出格式和限制。

2. 安装与首次配置

第一次使用只需要完成两件事：打开应用，连接一个可用模型。后续高级功能可以慢慢配置。

支持平台

平台 安装包 说明
macOS .dmg、.app 支持 Apple Silicon 和 Intel。顶部菜单栏会显示应用图标，窗口采用桌面应用布局。
Windows .exe 安装后启动桌面端，后端服务会随应用一起运行。
Linux .deb、.rpm 适合熟悉 Linux 环境的用户，可能需要按发行版处理系统依赖。

首次打开会看到什么

欢迎页或问答首页

如果是第一次启动，可能会出现模型配置或跳过配置入口。完成后进入问答首页。

本地后端自动启动

桌面端会启动本机服务，用来处理文件、会话、工具调用、SSE 流式输出和存储。

选择模型来源

没有可用模型时，输入框会提示先配置服务商。进入设置 → 服务商即可配置。

选择模型来源

方式 适合谁 优点 注意事项
自有 API Key 已有 OpenAI、Anthropic、Google、DeepSeek 等账号的用户 请求直接走自己的服务商账号 需要自己管理密钥、余额和服务商可用性
OpenAI 兼容端点 使用公司内网、代理网关或私有模型服务的用户 可连接兼容 OpenAI API 的模型服务 需要确认 base URL、模型名和接口兼容性
Ollama 本地模型 重视隐私、希望离线使用的人 模型在本机运行，适合敏感资料 效果和速度取决于电脑配置和所选模型
本地 API / 自定义端点 公司内网、私有模型、高级用户 可连接 OpenAI 兼容接口 需要确认端点支持 /v1/chat/completions
新手推荐 如果你只想快速开始，优先配置已有模型服务商的 API Key 或 OpenAI 兼容端点。如果你需要处理敏感内部文件，优先了解 Ollama 本地模型。
配置完成的判断标准 回到问答首页后，模型下拉里至少能看到一个可选模型；输入一句“用三句话介绍你能帮我做什么”，AI 能正常流式回复。满足这两点，就可以进入真实办公任务。

3. 十分钟完成第一个任务

下面用“把会议记录整理成行动清单”作为第一个示例。你可以把会议记录换成任何真实文档。

新建对话

点击左侧新建对话，或回到问答首页。

选择模型

输入框左下角或顶部会显示模型。新手不用纠结，默认可用模型即可。

上传会议记录

点击加号选择文件，支持 DOCX、PDF、TXT、Markdown 等。文件上传后会显示为标签。

选择“先询问”或“先规划”

第一次使用建议不要直接使用自动修改。普通总结任务通常不会改文件，但养成确认习惯更安全。

发送任务

复制下面的提示词，替换成你的实际要求，然后点击开始。

第一个任务提示词 
请阅读我上传的会议记录，整理成一份适合发给团队的会议纪要。
请按以下格式输出：
1. 会议主题
2. 三条关键结论
3. 决策事项
4. 行动项表格：任务、负责人、截止日期、优先级
5. 一封可以直接发送的会后跟进邮件

拿到结果后怎么继续

  • 如果太长，说“压缩到 300 字以内”。
  • 如果太口语，说“改成正式商务语气”。
  • 如果缺负责人，说“把不明确的负责人标成待确认”。
  • 如果要发邮件，说“生成一封邮件，主题和正文分开”。
  • 如果要保存，说“把会议纪要保存为 Markdown 文件”。

4. 界面导览

WorkCraft 的主要界面可以分成五块：左侧会话栏、中间对话区、底部输入框、右侧工作栏/产物栏、设置中心。

产物面板会把 AI 生成的报告、网页、表格或文件预览独立出来，方便在右侧直接查看。上传 Excel 或 CSV 后，也可以让 AI 提炼趋势、异常、结论和汇报话术。

左侧会话栏

查看历史会话、新建对话、搜索对话、进入设置。设置页会替换成专门的设置导航。

问答首页

包含欢迎语、输入框、模型下拉、工作模式、工作区按钮、附件按钮和快捷任务分类。

对话页

显示用户消息、AI 流式回复、活动摘要、文件卡片、权限确认、计划审阅和追问输入框。

右侧工作栏

显示任务进度、生成文件、Scratchpad、工作区记忆、连接器和技能。

产物面板

预览 AI 生成或展示的 Markdown、HTML、表格、PDF、PPT、流程图、代码等。

设置中心

配置外观、模型服务商、权限、自动化、插件、远程访问、用量和记忆。

界面使用顺序 新手只需要记住一条主线：先在输入框说清任务，再看中间对话结果；如果出现右侧产物面板，就在那里检查和下载结果；如果弹出权限确认，先看路径和动作再决定。

6. 问答与提示词写法

对于办公小白，提示词不用复杂，但要说清楚。最稳定的结构是：目标 + 材料 + 输出格式 + 限制条件。

不推荐

“帮我看看这个文件。”

这个说法没有明确结果，AI 可能只给泛泛总结。

推荐

“阅读这份销售表，找出本月增长最快和下降最多的产品，输出表格，并写 5 句适合周会汇报的话术。”

目标、材料、格式和用途都清楚。

好提示词的四个组成部分

目标

说明最终要什么，例如“生成周报”“整理行动项”“找风险”。

材料

说明看哪些文件、哪个文件夹、哪段背景。

格式

说明输出成表格、清单、邮件、报告、网页、PPT 大纲。

限制

说明字数、语气、不要改原文件、先问我、只看本周资料。

受众

说明给老板、客户、同事、财务、法务还是自己看。

下一步

说明是否需要保存文件、生成图表、导出或继续追问。

7. 文件、附件与工作区

WorkCraft 的强项是处理真实办公文件。你可以上传单个文件，也可以选择一个文件夹作为工作区。

DOCX XLSX PPTX PDF CSV Markdown HTML TXT 图片

什么时候用上传文件

  • 只需要处理一两份材料。
  • 文件不在同一个文件夹里。
  • 只是临时分析，不需要形成长期工作区记忆。
  • 手机远程任务需要拍照或上传附件。

什么时候用工作区

  • 任务涉及一个文件夹里的多份文件。
  • 需要跨文件搜索和 @ 文件引用。
  • 需要生成文件并保存到这个项目目录。
  • 这是一个长期项目，希望后续保留记忆。
新手安全建议 第一次不要把“整个电脑”交给 AI。先建一个测试文件夹，把要处理的文件复制进去，再选择这个文件夹作为工作区。

工作区记忆

工作区记忆会按文件夹保存。它会从对话中提取对后续有用的信息，例如项目背景、客户偏好、常用格式、已完成事项。你可以在右侧工作栏查看，也可以在设置 → 记忆中编辑、导出或删除。

8. 工作模式、权限与计划审阅

WorkCraft 能读取和修改文件，也能运行工具。为了避免误操作，它提供三种工作模式和明确的权限确认。

先规划

只分析、拆解、提交计划，不直接修改。适合重要资料、复杂任务、批量操作。

新手首选

先询问

执行前会询问你，尤其是写文件、编辑文件、运行命令。适合日常任务。

推荐默认

自动修改

AI 自动执行，减少打断。只适合你信任工作区和任务范围的时候。

谨慎使用

权限弹窗怎么判断

权限 它想做什么 新手怎么判断
Read 读取文件或目录，不修改文件 路径在你的工作区内且和任务相关，通常可以允许
Write 创建或覆盖文件 确认文件名和目录正确；重要目录不要直接允许覆盖
Edit 修改已有文件 重要文件先备份；不确定就让 AI 先给修改计划
Bash / 命令 运行系统命令，可能改变文件或环境 看不懂就拒绝，并要求 AI 用中文解释命令用途
Web Search / Web Fetch 搜索网页或抓取网页内容 适合查公开信息；不要让敏感内部资料外发

计划审阅

当 AI 准备执行复杂任务时，可能会提交计划。你可以选择“接受并自动执行”“接受并逐步确认”或“不，继续规划”。批量整理文件、改多个文件、生成多份材料前，建议先看计划。

9. 结果、产物和导出

WorkCraft 的输出分为三类：文字结果、过程记录、可复用产物。

文字结果

报告、总结、邮件、建议、计划、风险清单、表格文字等。

过程记录

活动面板会显示 AI 的思考、工具调用、读取文件、搜索结果和耗时。

产物文件

Markdown、HTML、图表、CSV、文档、表格、流程图和预览文件。

产物面板能看什么

Markdown 报告 HTML 网页 React 预览 SVG 图形 Mermaid 流程图 代码 CSV DOCX XLSX PDF PPTX

如果同一个产物被多次更新，面板顶部会显示版本切换。生成多个产物时，也可以在顶部左右切换。

导出方式

  • 对话顶部导出按钮：把当前会话导出为 PDF。
  • 产物面板下载：Markdown、PDF 或文件预览可通过对应渲染器保存。
  • 让 AI 保存文件：可以直接说“保存为 Markdown/HTML/CSV 文件”。
  • 工作栏 Files：点击生成文件可再次打开预览。

结果验收清单

AI 给出结果后，不建议直接复制发送。办公场景里至少检查下面六项。

  • 事实是否来自你提供的文件，还是 AI 自己推测。
  • 数字、日期、金额、姓名、合同条款是否准确。
  • 输出格式是否符合目标，例如表格列名、邮件主题、汇报结构。
  • 语气是否适合接收对象，客户、老板、同事的表达要区分。
  • 是否遗漏“待确认”事项，不能确定的信息不要让 AI 硬填。
  • 生成文件是否保存在正确工作区，文件名是否容易识别。
让 AI 自检结果 
请对刚才的结果做一次自检：
1. 列出你使用了哪些文件或信息来源
2. 标出可能不确定或需要人工确认的内容
3. 检查数字、日期、姓名、金额是否前后一致
4. 给出一版更适合直接发送的最终稿

11. 自动化任务

自动化适合重复办公流程，比如每日摘要、每周周报、文件夹检查、定期整理和循环处理。

定时执行

按时间或间隔运行，例如每天 8:00、工作日 9:00、每 2 小时一次。

循环执行

让 Agent 反复处理任务，最多执行指定轮数。输出中包含 [LOOP_DONE] 可提前停止。

创建自动化的推荐流程

进入设置 → 自动化 → 新建任务

填写名称和描述，例如“每日项目摘要”。

写提示词

说明要检查哪个文件夹、输出什么、是否需要保存结果。

选择任务类型和时间

日常固定任务选定时；需要持续处理队列选循环。

选择模型和工作区

不确定模型就选择自动；工作区必须选准确。

先立即运行测试

结果正确后再开启定时开关。

自动化任务示例：每日摘要 
请每天汇总这个工作区中今天新增或修改过的文件。
输出：
1. 新增或修改的文件列表
2. 每个文件一句话摘要
3. 需要我明天继续跟进的事项
4. 一段可以发到团队群的简短日报
如果没有变化，请只输出“今天没有检测到重要更新”。

12. 插件、连接器与技能

插件、连接器和技能是增强能力。普通办公任务可以先不用配置；当你需要接入外部系统、知识库或专业流程时，再打开设置 → 插件。

连接器

连接外部工具或 MCP 服务。可启用、授权、断开、重连，也可添加自定义 MCP 地址。

插件

插件提供一组扩展能力和工具，界面会显示版本、描述、是否启用和依赖。

技能

技能是针对特定任务的操作指南。可以启用内置技能、插件技能、项目技能，也可从技能商店安装。

13. 手机远程与消息渠道

远程访问让你用手机控制电脑里的 WorkCraft。任务仍然在电脑上执行，手机负责发送任务、查看结果、补充回答和处理确认。

开启远程访问

电脑端打开设置 → 远程

打开远程访问开关，等待隧道启动。

显示二维码

用手机扫码，或复制链接到手机浏览器。

手机端保存连接

手机会保存 URL 和 token，之后进入任务列表。

创建手机任务

手机端可选择模型、工作区，拍照上传或上传附件。

远程权限模式

模式 含义 推荐场景
自动批准安全工具 减少低风险确认 总结、查看、轻量任务

14. 常见办公场景教程

下面是最适合普通办公用户直接上手的场景。每个场景都建议先用测试资料跑一遍。

Office SOP
处理任何办公任务，都可以套用这套固定流程。
准备材料

把相关文件放进一个清晰命名的文件夹，例如“2026-05 销售周报资料”。重要原件先备份。

先让 AI 复述任务

发送任务后先要求 AI 说明它理解的目标、材料范围和输出格式，避免一开始就跑偏。

分阶段交付

先要大纲和计划，再要正式稿；先看预览，再让 AI 保存文件或批量修改。

会议纪要变行动清单

上传会议记录，让 WorkCraft 输出结论、决策、行动项、负责人、截止日期和跟进邮件。

销售表格分析

上传 Excel/CSV，找趋势、异常、Top 产品、下滑原因，并生成周会汇报话术。

合同风险初筛

上传合同 PDF，让 AI 初步筛查付款、违约、交付、保密、自动续约等风险。

PPT 审阅

上传 PPTX，让 AI 检查每页逻辑、证据缺口、标题表达和 speaker notes。

桌面文件整理

选择测试文件夹，让 AI 先规划分类规则，再逐步移动、重命名或生成索引表。

周报/月报生成

选择项目工作区，让 AI 读取本周更新资料，生成进展、风险、计划和待确认事项。

个人或产品网页

让 AI 生成 HTML 页面，在产物面板预览，再保存为可发送的网页文件。

重复任务自动化

把每日摘要、每周资料检查、定期整理设置为自动化任务，定期查看运行结果。

跨文件综合报告

把 memo、预算表、PPT、PDF 放入工作区，让 AI 综合成一份管理层 brief。

15. 常用提示词库

以下提示词可以直接复制。建议每次补充“受众、字数、语气、是否保存文件”。

文件总结 
请阅读我上传的文件，整理成一份适合办公汇报的摘要。
请按以下格式输出：
1. 三条关键结论
2. 重要数据或事实
3. 风险与注意事项
4. 下一步行动建议
5. 可以直接发给同事的简短消息
要求：语言简洁，适合发给团队负责人。
表格分析 
请分析这份表格，帮我找出：
1. 总体趋势
2. 增长最快和下降最明显的项目
3. 异常数据
4. 可能原因
5. 适合放进周会汇报的 5 句话
如果适合，请生成一个图表或汇总表格。
会议纪要 
请把这份会议记录整理成正式会议纪要。
输出：
1. 会议主题
2. 参会人
3. 讨论要点
4. 决策事项
5. 行动项表格：任务、负责人、截止日期、优先级
6. 一封可直接发送的会后跟进邮件
文件整理，先规划 
请先不要修改文件。
请扫描当前工作区，帮我设计一个文件整理方案：
1. 当前文件类型和数量
2. 建议创建的文件夹结构
3. 每类文件的移动规则
4. 可能有风险或不确定的文件
5. 需要我确认的问题
等我确认后，再逐步执行。
周报生成 
请根据当前工作区中本周更新过的文件，生成一份项目周报。
格式：
1. 本周完成
2. 关键进展
3. 数据或证据
4. 风险与阻塞
5. 下周计划
6. 需要领导确认的事项
语气正式、简洁，适合发给团队负责人。
网页生成 
请生成一个单页 HTML 页面，主题是：[主题]。
要求：
1. 首屏直接展示主题和核心信息
2. 包含介绍、亮点、使用步骤、联系方式四个部分
3. 风格简洁专业，适合办公展示
4. 生成后在右侧产物面板预览
5. 同时保存为 HTML 文件

16. 隐私、安全与好习惯

WorkCraft 默认本地优先：文件、对话、工作区记忆和生成产物存储在本机。使用云端模型时，相关提示词和必要上下文会发送给你选择的模型服务商；使用 Ollama 本地模型时，可减少云端调用。

建议做法

  • 重要文件先备份。
  • 复杂任务先用“先规划”。
  • 每个任务选择明确工作区。
  • 权限弹窗认真看路径和命令。
  • 敏感资料优先使用本地模型或脱敏文件。

不建议做法

  • 第一次就开放整个电脑。
  • 不看路径就允许写入或编辑。
  • 把密钥、证件号、银行卡等直接发给云模型。
  • 对不了解的命令选择“记住允许”。
  • 自动化长期启用但从不检查结果。

17. 常见问题处理

问题 可能原因 处理方式
输入框提示暂无可用模型 未配置服务商，或服务商连接失败 进入设置 → 服务商，配置 API Key、连接 OpenAI 兼容端点或启动 Ollama
上传文件失败 文件过大、路径不可读、文件被占用、后端未就绪 换小文件测试，确认文件未被锁定，重启应用后再试
AI 找不到工作区文件 未选择工作区、索引未完成、文件不在目录中 重新选择工作区，等待 Indexing 完成，或用 @ 精确引用文件
结果太泛泛 任务目标不清晰 补充输出格式、受众、字数、数据范围和你关心的问题
权限弹窗看不懂 AI 想读写文件或运行命令 不确定就拒绝，并让 AI 解释为什么需要这个权限、会改哪些文件
远程手机连不上 隧道未开启、令牌过期、URL 已变化 电脑端设置 → 远程重新显示二维码，手机重新扫码。必要时刷新令牌
自动化没运行 任务未启用、时间配置不对、模型不可用 检查开关、下次运行时间、模型设置。先点“立即运行”测试
成本上涨很快 模型较贵、文件很大、对话很长或自动化太频繁 在用量页查看高消耗会话，换低价或本地模型，压缩上下文，减少自动化频率

18. 术语表

模型

提供 AI 能力的大语言模型，例如 OpenAI、Claude、Gemini、DeepSeek、Ollama。

服务商

提供模型访问的来源，例如自有 API Key、OpenAI 兼容端点、自定义端点、本地 Ollama。

工作区

你指定给 AI 处理的文件夹。建议每个项目或任务选择一个明确工作区。

产物 Artifact

AI 生成的可复用内容，例如报告、网页、表格、代码、流程图、文件预览。

Token

模型计算文本长度和费用的单位。文件越大、对话越长，tokens 越多。

上下文

AI 当前能看到的对话历史、文件摘要、工作区记忆和相关材料。
